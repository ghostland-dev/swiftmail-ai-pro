# SwiftMail

Email client with folders and search.

## Features

- Folder view
- Search results
- Settings

## Tech Stack

- Vite
- React
- TypeScript
- Tailwind CSS
- shadcn/ui (Radix UI)
- TanStack Query
- React Router
- Framer Motion

## Getting Started

```bash
git clone https://github.com/ghostland-dev/swiftmail-ai-pro.git
cd swiftmail-ai-pro
npm install
npm run dev
```

Other scripts:

- `npm run build`: vite build
- `npm run lint`: eslint .
- `npm run preview`: vite preview
